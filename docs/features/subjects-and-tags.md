# 学科与扁平标签

学科用于隔离题库、权限和配置；题目可绑定多个扁平标签，支持命中任一或同时包含全部。空标签条件不限制题池，分组不参与匹配运算。

## 学科

新建、编辑、删除学科仅限超级管理员。字段包括名称、唯一标识 slug、描述、审核阈值 required_review_count。各学科保留自己的知识点树、审核流程和成员权限。

## 标签与分组

同学科标签名称唯一，跨学科不能引用。每个标签可以放入一个分组或保持未分组；分组仅用于管理和展示，没有分类树、父子继承或按组自动匹配。标签使用稳定 ID，改名和移动分组不改变模板引用。

学科负责人管理标签和分组，普通成员按授权查看。标签支持新建、编辑、启停、引用查看；被题目或模板引用时不能直接删除，建议停用。停用标签保留旧关联，不能新增绑定；引用它的模板生成前必须修正。非空分组禁止删除，删除分组不会级联删除标签。

题目列表支持多选标签与 any/all 匹配，批量维护支持追加、替换、移除和清空。批量 ID、学科或权限错误会整批回滚，标签更新不改写题干和答案。

## 多标签组卷

模板保留分区。每条抽题规则可选择五种固定题型之一、多个标签、全部/任一、题量和每题分值；同题型可以添加多条独立规则。全卷范围与规则条件同时生效。生成时可以继承、临时替换或清空全卷范围，实际条件保存到批次快照。

先预检再生成：阶段数量只统计授权可见题目。组卷同时满足发布状态、答案有效性、学科、权限、题型和标签条件，整批统一分配；组合冲突明确提示，失败不会留下残套。

默认初级岗考核卷有 12 条规则、25 题、100 分，业务与技术各 50 分。种子不自动给原题打标签，需人工整理后再预检。

Excel 标签导入沿用现有模板，其中“分类”列表示标签分组。模板/AI 提取只自动绑定当前学科已启用的明确匹配项，其他建议留在复核界面，不自动创建标签。
